its python script and to avoid ban we should run it using ws-proxy

---------------------------ws-proxy-installation--------------------

download it inside machine or using free server service like : https://railway.com/ :via github account


inside vps machine : 

git clone https://github.com/Fiujol/proxy            : also i have it with .zip format 


unzip it

cd proxy

npm install

npm i -g pm2

pm2 start index.js --name="proxy"

then the public url it should like that : wss://VPS_PUBLIC_IP:5999/ ( to incluce it inside dataset file)

----> to test it it really run then : http://VPS_PUBLIC_IP:5999/----->> wsProxy running...
